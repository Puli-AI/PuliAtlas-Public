# 04 — Public Roadmap

## 0.x — Document and prove

- publish product principles and the draft schema;
- release a generic demonstration with invented content;
- build a native YAML/JSON renderer;
- validate stable IDs, backlinks and public/private boundaries;
- document deployment to common static hosts.

## 1.0 — Single-site publisher

- supported schema and command-line builder;
- index, graph and focused-card themes;
- stable URLs, search, backlinks and multilingual bundles;
- accessibility, reduced motion and performance budgets;
- reproducible releases and migration notes.

## 1.x — Import and extend

- Markdown/wiki-link importer;
- tested Roam Research export importer;
- theme tokens and plugin hooks;
- comments/community adapters;
- reference deployments and authoring previews.

## 2.0 — Hosted PuliWeave beta

- accounts, projects and private preview builds;
- visual card and relationship editor;
- publishing destinations and custom domains;
- audit, usage, billing and support foundations;
- strong tenant isolation and deletion/export controls.

## 3.0 — Governed knowledge publishing

- team workflows and permissions;
- multiple workspaces and publication channels;
- AI-assisted link suggestions with human approval;
- enterprise audit, retention and regional options;
- a documented extension ecosystem.

## Non-goals for the first release

- replacing the user’s note-taking system;
- publishing an entire private graph by default;
- requiring a database to read a static site;
- presenting AI-generated relationships as facts;
- cloning any referenced product’s interface or branding.
