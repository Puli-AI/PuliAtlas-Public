# Contributing to PuliWeave

PuliWeave is currently a documented concept, not yet an open contribution project.

Early public feedback will be most useful on:

- the publishing problem and audience;
- the draft content and relationship schema;
- privacy risks in public graph export;
- accessibility of graph navigation;
- import formats and deployment targets.

Before accepting code contributions, the project will publish:

- a formal licence;
- a code of conduct;
- contribution and review rules;
- a security-reporting route;
- a clear trademark policy.

Do not submit Puli Consulting private content, client material, credentials or third-party copyrighted exports.
